## Suggested demo flow

1. Show the SECMS Lightning app and its tabs (Student, Course, Instructor, Enrollment).
2. Create a student with a valid `@student.edu` email, then try an invalid email to show the validation rule.
3. Create an enrollment: the Enrollment Date is filled in automatically by the flow.
4. Show the instructor being auto-assigned based on the course category (Technical, Language, Non-Technical).
5. Try to approve an enrollment with fees unpaid to show the "Fees must be paid" validation rule.
6. Submit the enrollment for approval and approve it; show the status update and email alert.
7. Show the follow-up task created for the admin.
8. Open the reports and the Student Management Dashboard.
